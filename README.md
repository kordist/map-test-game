# 💻✨ Laptop Hero
### 1st Grade Computer & MAP Test Practice Game

A playful, interactive practice app designed for 1st graders mastering laptop trackpad, cursor navigation, double clicking, drag-and-drop, scrolling, and audio listening for standardized MAP testing.

🌐 **Live Game:** [https://kordist.github.io/map-test-game/](https://kordist.github.io/map-test-game/)

---

## 🎮 Skill Missions

1. **🐭 Mission 1: Cursor Master** — Smooth mouse and trackpad movement, star catching, and path tracing.
2. **🥚 Mission 2: Click & Double-Click** — Cracking dragon eggs with fast double-clicks and popping balloons.
3. **🪄 Mission 3: Drag & Drop Wizard** — Pet feeding, 10-frame math counters, and word builders.
4. **🌊 Mission 4: Super Scroller** — Two-finger trackpad/scroll-wheel navigation to read stories and explore deep oceans.
5. **🎧 Mission 5: Super Listener** — Patiently listening to spoken directions completely before answering.
6. **🍎 Special Quest: Save the Apple!** — Strategic block-placement to stop the hungry caterpillar across converging garden trails.
